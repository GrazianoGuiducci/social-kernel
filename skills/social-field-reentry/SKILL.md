# Social Field Reentry

Recover the smallest present sufficient to form the current movement. Read the
user's current entry and decisive owner-native sources; this repository's
CURRENT describes the product, not the user's social activity.

## Recover relations, not an archive

Determine the current purpose and the material difference that makes work
pertinent. Recover only the related:

- operator direction and its source, separated from receiver proposals;
- source or product facts and their applicable version;
- occurred effects, exact identities and open consequences;
- independent mentions, listings or propagation when they change the field;
- people, conversations, relationship state and next trigger owner;
- prepared materials and later corrections to their applicability;
- current authority, controller and actual observation or action means.

Use the [receiver contract](../../docs/RECEIVER_CONTRACT.md) if host capability
or persistence is not yet bound.

Follow the entry into deeper sources when meaning or an unresolved consequence
can change the decision. Do not reopen closed work without a new material
difference. An unrelated project's current cursor does not select this movement.

## Establish the relevant present

Search results, memory, an old checkout or a saved browser tab are not necessarily
current. When drift could change the decision, resolve the current owner
identity and read the decisive source or native object. Preserve time and coverage.
If a fetch fails, retain that failure against its source; do not reuse another
source's previous response body as though the failed read succeeded.

Individually accurate fragments can describe a present that never existed.
Check whether the source version, conversation state and authority actually
apply together. Later facts do not retroactively change earlier awareness.

Read accessible corrections and follow-up to an incoming handoff before using
its artifact. A downloaded file may have been superseded in its source
conversation. Preserve unavailable follow-up as a specific uncertainty.

## Recompose instead of replaying

Keep occurrence, understanding at the time, later consequence and current
interpretation distinct. If a receiver's proposal was persisted as operator
direction, recover the attributed source and correct that entry; repeating Boot
alone would replay the substitution.

Reach the competence that can change the question before choosing an answer.
An existing owner may already know the method; repair routing before inventing
another skill.

If access is partial, identify the missing object or observation. An invisible
comment is not evidence of deletion; one inaccessible page does not prove the
platform unavailable. Form an exact read-only delegation when an authorized
receiver can resolve the gap.

## Return a usable present

Return the material change, evidence or uncertainty, useful movement and what
would change it. Retain no_change only for inspected objects and coverage.
Use [state contracts](../../docs/STATE_AND_RECORDS.md) for durable continuation.

For a proposed write, continue through [effect boundary](../social-effect-boundary/SKILL.md).
An older queue, schedule or packet does not settle present eligibility.
