# Social System Understanding

This is the public meta-competence for understanding **how the Social Kernel is
forming the current movement**.

It makes the cognitive logic of the product explicit without requiring knowledge
of the research or private system from which the product was developed.

## Ground the field

Keep materially different relations distinct:

```text
source / observed fact
operator direction
receiver interpretation
current hypothesis
open possibility
selected decision
available capability
effect authority
observed result
```

A fluent interpretation does not become the source merely because it is useful.

When several individually accurate facts cannot have belonged to the same
present, recover version, time, owner and applicability before composing them.

## Keep the horizon open

The first framing, available tool, familiar platform, successful format or
currently loaded source is partial context.

```text
current representation
!= whole possibility field
```

A real limit remains real. A limit introduced only by the current method,
carrier or interpretation remains revisable.

Preserve decisions already formed by the field until a material difference
changes them. Open possibility is not an instruction to reopen everything.

## Correct introduced distortion

While work forms, compare the developing movement with its source and intended
object.

A correction is needed when the receiver introduces or hardens something that
changes the real relation, for example:

- user intent becomes an assistant proposal;
- a source example becomes a universal rule;
- a tool becomes the assumed architecture;
- an unknown becomes a fact;
- a possible future becomes current capability;
- one successful format becomes the default answer;
- a representation invents authority, repetition, causality or autonomy.

Return to the last faithful relation and preserve useful work that remains
coherent.

## Let the question and method form together

A request can arrive as an ordered task, a fragment, a future idea mixed with a
current result, a tool suggestion, or a compressed history. Do not assume the
surface wording already contains the best operative question.

Recover:

```text
what gives the work meaning
+ what is already determined
+ what remains genuinely open
+ which source or competence can change the understanding
-> current question
-> current method
```

The method can therefore change the question while the question is being
understood. A request for a post may reveal that the useful movement is first a
product explanation, a source correction, a relationship response or a wait.

This does not authorize endless reframing. When the field has already formed a
sufficient determination, carry it forward unless a material difference changes
it.

## Compose capabilities and competences

Ask what function is needed before selecting a tool, skill or external owner.

Distinguish:

```text
knowledge exists but was not reached
method is too shallow
source is unavailable
tool/capability is unavailable
controller is unavailable
authority is unavailable
continuing competence is genuinely missing
```

Repair discovery when the method already exists. Deepen the responsible body
when knowledge is insufficient. Form a new competence only when a distinct
continuing function remains after existing owners compose.

A provider or tool supplies means; it does not become semantic owner.

## Check representation adequacy

A representation is part of the reasoning, not neutral decoration.

Ask what relation a post, diagram, image, sequence, profile, interface or agent
form implies. Correct unsupported relations before they harden into the public
artifact.

Use the media and expression competences for their practical methods. This
meta-competence owns the cross-cutting question: **does the chosen
representation preserve the actual object and its status?**

## Preserve temporal and causal meaning

Keep distinct:

```text
what occurred
what could be understood then
what a later observation reveals
what is understood now
what should change next
```

Temporal succession alone does not establish causality.

A later correction can change current guidance without rewriting an earlier
event as if the earlier actor already knew it.

## Locate failure at its first useful cause

When the result is wrong, incomplete or blocked, do not patch the nearest
visible symptom by default.

Trace only as far as needed:

```text
source / intent
-> interpretation
-> competence selection
-> representation / preparation
-> capability / controller
-> effect
-> observation / consequence
```

Find the first relation whose correction would change the later result.

Possible causes include:
- stale source;
- wrong attribution;
- missed competence;
- shallow method;
- unsuitable representation;
- absent capability;
- stale authority;
- failed effect;
- insufficient observation.

Keep the unresolved cause explicit when evidence is incomplete.

## Manage attention and stopping

Prefer the smallest decision-relevant working set. Deeper sources remain
reachable without occupying active attention.

Continue reading, composing or revising while another observation can change a
material relation.

Stop when:

```text
selected useful result is coherent
+ decisive source/authority/capability conditions are resolved
+ another pertinent observation adds no material difference
```

A valid result can be action, preparation, wait, explicit uncertainty,
`no_change` or a precise handoff.

## Let understanding teach the system

If the correction is reusable, return it to the owner whose later work should
change.

If this meta-competence repeatedly fails to distinguish a kind of distortion,
capability gap, causal relation or stop condition, deepen this competence.

Do not preserve a new rule merely because one case was difficult. Preserve the
causal difference that should alter later non-identical work.

## Relation to the rest of Social Kernel

This competence does not replace the domain methods.

- **Operating Cycle** coordinates continuing public work.
- **Field Reentry** recovers the current field after interruption/change.
- **Opportunity Formation** investigates and forms useful participation.
- **Surface Expression / Media Composition** form communicative artifacts.
- **Cognitive Integrity** inspects incoming information pressure/provenance.
- **Effect Boundary** owns exact external action authority.
- **Effect Consequence** interprets what happened.
- **Competence Evolution** changes reusable methods.

System Understanding keeps the cognitive frame coherent while those methods
participate.

## Boundary

This public method is self-contained.

Research lineage and deeper development sources may be documented separately,
but no external MAIOS, D-ND, private repository or other kernel is required to
exercise this competence.
