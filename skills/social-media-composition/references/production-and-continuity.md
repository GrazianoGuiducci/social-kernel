# Media production and continuity

Use this reference when a selected social movement needs an actual media file
or a revision of one. Keep the work proportional: a single image may need a
short production note; a family of derivatives may need an asset record and
shared editable source.

## Resolve the actual production path

Match the artifact to an operation the receiver can perform. An available
generator can create imagery; a vector or layout tool can place exact text; a
chart tool can map supplied values; a video tool can execute a temporal
composition. A browser or editor can sometimes provide another path. Use the
current host's capabilities and instructions, including permitted reference
inputs and output handling.

Inspect an existing file before transforming it. Determine whether the best
next operation is reuse, a targeted edit, a derivative or a new composition.
Preserve the user's selected material and its provenance. Reach current source
facts when a visual's text, event, claim or intended use may have changed.

If a needed operation is unavailable, specify what is missing: for example,
generation of the selected illustration, rendering the editable composition,
export to a supported format, or inspection of video playback. A concrete
brief and source set let another receiver continue. State which files already
exist and which remain preparation. Continue independent useful work while
the dependent operation stays unresolved.

## Give the tool a formed brief

Carry enough concrete information for the selected operation:

- The subject and relation that should become perceptible.
- The chosen composition, hierarchy and intended viewing situation.
- The actual supplied references, with what each contributes.
- The identity, wording, geometry or content that must remain stable.
- The transformation requested and the freedom available to the tool.
- Required output properties that the current destination actually needs.

These are useful relations, not required fields in a universal form. A tool
with a small input surface may receive one concise instruction; another may
need separate assets, exact text and layout dimensions.

When using reference images, distinguish the real subject, a selected prior
artifact and a style reference. State which properties may travel from each.
An unrelated reference's logo, product, people or claim does not become part of
the new subject through stylistic similarity.

Use [user-field projection](../../social-user-field-projection/SKILL.md)
before private information enters a generation prompt, external search or
other tool request. Include only what that particular operation needs at the
permitted depth.

Exact facts deserve a production path that can preserve them. Prefer an
editable layer for dates, URLs, figures, labels and marks when their correctness
matters. When all elements are rasterized, retain an editable source or the
production instructions that would make a correction practical. Read the
actual final spelling and placement; successful generation alone leaves those
properties unknown.

## Produce, inspect and correct

Invoke the real operation and retain its actual result. Record tool or model
identity and material settings only to the extent the host exposes them and
they help later continuation. A saved prompt can explain an attempt without
guaranteeing exact reproducibility.

Inspect the artifact at its native dimensions and at the intended reading
scale. Check a target crop or preview when that format matters. A full-image
inspection can miss a headline cut off by a narrower presentation. Check
actual platform constraints from current sources when an exact export or
publication depends on them; preserve uncertainty when that surface cannot
be inspected.

For a still image or diagram, read:

- The subject and dominant relation before consulting the author's explanation.
- Visual hierarchy, text size, contrast, spacing and crop.
- Exact names, values, dates, destinations, marks and attribution.
- Any implied action, causality, availability or state introduced by the form.
- Agreement with the selected copy and the supported brand or profile.

For a sequence or audiovisual artifact, also inspect the actual order, pacing,
visible change, narration/caption agreement and recovery of meaning without
sound or unnecessary motion. A storyboard carries planned events; playback
is evidence about executed time.

Use this observation to choose the smallest useful correction. An edit request
should identify the defect and the elements to preserve. If the tool cannot
reliably keep exact details, choose a more controllable layer when available.
If a deeper mismatch appears, return to source or composition instead of
iterating local visual polish.

Alternative text should describe the information and function of the final
selected image. Captions and transcripts should match what was produced.
A technical proof or statistic retains an inspectable evidence route outside
the decorative image where needed.

Keep the scope of the observation precise. A readable local preview establishes
that local reading under the inspected conditions. Another person's
comprehension, actual feed behavior and publication outcome need their own
observations.

## Preserve a recoverable artifact family

Store finished and editable files in the continuity location selected by the
user and supported by the host. Preserve useful originals while making
derivatives. Use stable identities or explicit paths; obtain an actual
retrievable result rather than leaving the only copy behind a temporary
preview.

Keep the smallest record that explains:

| Relation needed later | What to preserve |
| --- | --- |
| Why this artifact exists | Source or source version, purpose, selected receiving situation. |
| What was made | Actual media file, format/dimensions when material, editable master or input assets if available. |
| How this revision arose | Parent asset or shared source, actual production/edit instruction, material settings if exposed. |
| What was observed | Inspected revision, crop/scale or playback scope, consequential findings and remaining gaps. |
| Which version to use | Selected revision and reason, superseded candidates when useful, related copy/alt-text revision. |
| What changes next time | Relevant source/profile changes, dependent variants, local method and its entry. |

This is a semantic record. A Markdown note, existing asset manager or local
project convention can carry it without a new database or mandatory schema.

When preserving a snapshot, retain its source identity and original location
or reference base. Relative links derive their meaning from that base; copying
the same bytes to another folder can change what they reach. Keep historical
archives distinguishable from active navigation. An archive can preserve its
original references with their base made explicit, while an active index or
adapted projection supplies usable routes from the new location.

After copying, moving or transferring a family, follow its material references
from the receiving entry, including the linked assets, methods and source
projections. Verify the routes the consumer actually exposes. A check of the
original tree or only the top-level index does not establish reachability of
the copied material. State the inspected coverage and any unresolved route;
preserve the historical record when correcting its active projection.

A selection applies to a named purpose and situation. Preserve accepted
features separately from a decision about the whole artifact. A recently
generated variant remains an experiment until the current selection changes.
Exporting an image does not publish it; publication has its own authority,
controller and receipt.

If durable storage is unavailable, return the accessible files and the
continuation note through the supported host mechanism, state the persistence
limit and leave the exact saving step to a capable receiver. Do not claim
continuity from an inaccessible path or a digest with no retrievable file.

## Continue after a material change

Recover the selected artifact, its source relation and the actual new condition.
Determine what remains valid and which copy, labels, crops or derivatives depend
on the changed relation. A date change may alter exact text; a changed service
may require a different scene or invitation; a new receiving context may
need a different emphasis or medium.

Preserve the earlier occurrence and reason while forming the current version.
An asset can remain visually attractive and become unsuitable for its prior
use. Make the selected current revision reachable so the next receiver does
not resurrect the old variant from recency or filename alone.

Derive from the shared meaningful source when changing surfaces. Reflow,
crop, density and sequence may all change while the relevant relation stays
true. A carousel can reveal one part at a time; its first frame still needs an
intelligible subject, and its sequence must add useful understanding. Build
only the derivatives the selected work needs.

When the change teaches a reusable production or design relation, put that
knowledge in the local method or profile that will guide the next artifact.
Preserve its conditions and a reachable entry. Report whether later use
actually reached and exercised it; storage alone establishes only availability.
