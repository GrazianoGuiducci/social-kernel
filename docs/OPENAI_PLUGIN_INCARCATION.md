## Purpose

Install a persistent operating method for public presence into ChatGPT/Codex.

The first plugin does not need direct social APIs to be useful.

It can already guide:
- public-field reentry;
- opportunity/no-action formation;
- source-aware expression;
- event/consequence readback;
- relationship continuity;
- user-field projection;
- cognitive-integrity handling;
- learning return.

## Public boundary

User/project private knowledge stays local or in the user's selected MAIOS
continuum.

A surface tool receives only the smallest pertinent projection.

No plugin installation creates standing authority to publish, message, spend or
change an account.
