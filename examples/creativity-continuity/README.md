# Creative work that continues: Riva Print Room

This case uses an entirely fictional community print studio to exercise the
public Social Kernel outside its originating projects. It includes actual
created media, copy, source facts, production instructions, local inspection,
selection reasons and a later receiving movement.

The studio and events are fictional. The generated files and local inspections
are actual outputs of this internal exercise. No social post, message, real
participant response or audience outcome occurred.

## Source and receiving conditions

Two related internal AI receivers were given the same frozen portable bundle,
one after the other. Each began without the product construction conversation.
They could read that public source and the studio's saved field, use the actual
host tools and preserve local files. Original private repositories and installed
MAIOS/social method bodies were excluded from their task-specific sources.
The generic host instructions and tool catalog remained available.

The exercised source is [commit 08d61be](https://github.com/GrazianoGuiducci/social-kernel/commit/08d61bec187e384a89d700dd81ee407f5faad133).
It assembled 41 declared source files plus the portable inventory. The exact
source file map is in [exercised-source.json](exercised-source.json):

## First movement: make a print and take it home

The fictional operator supplied an Open Print Table for 17 October 2026,
15:00–17:00: free drop-in, materials provided, no prior experience needed.
Beginners make a simple paper print and take it home. The existing local voice
was clear, welcoming and direct; it supplied no logo, palette or poster system.
Concept, wording, medium and local creative production were delegated.

The first receiver formed the invitation “Make a print. Take it home.” and
produced one illustrated card through the built-in image generator. The
1122 × 1402 PNG exists, with a companion caption and alternative text. The
receiver and the parent author inspected the saved native image and a
375-pixel-wide local preview. Consequential words and event details were
readable under those conditions. No substantive visual correction was needed.

The receiver preserved the actual prompt, output, source snapshots, selected
revision and reasons. It extended the existing studio method with a situated
precedent: use a recognizable, attainable object to carry a making invitation
when that relation fits, and keep practical details legible. It preserved the
original voice and did not make the colors, wording or hands illustration a
permanent studio rule.

## Second movement: a different purpose

The later fictional operator task supplied a Mini-zine Exchange on 31 October
2026, 15:00–17:00. People can bring a handmade mini-zine to share or exchange;
a small table supplies paper, scissors and glue to make one there. Both
beginners and experienced makers are welcome. A supplied participant question
asks whether someone who has never made a zine can still join.

A fresh receiver entered the saved field, read its existing studio method and
opened the earlier selected print card. It formed “Bring one to share. Or make
your first here.” and generated a different 1122 × 1402 illustrated card: two
folded booklets at a shared table, with a warm apricot/plum treatment. The
earlier image was not supplied to the generator as a reference. The new card,
caption, alternative text and direct draft answer are retained. The receiver
and parent author inspected the native image and a 375-pixel-wide preview;
the booklets, joining routes and consequential event details remained readable
in those local views. No substantive visual correction was needed.

This movement used the earlier conditional guidance about a recognizable,
attainable object, while the new sharing purpose and beginner question changed
the composition and invitation. The old event's wording, palette and single
print image did not become requirements. The earlier contribution remains
complete for its own event.

The existing local studio method now also carries a conditional joining
distinction: when an invitation involves bringing finished work but the source
supports beginning there, make that alternative visible if preparation or
experience is a live uncertainty. The participant answer resolves the supplied
question using the actual materials and beginner welcome. Later use of this
new distinction remains unobserved.

## Assistance and practical limits

Both receivers used the generic host imagegen skill for tool operation, one
bounded text-only copy-review agent each and the parent author's subsequent
visual review. The first copy reviewer suggested retaining the year in a
standalone caption; that small change was applied. The second offered a
source-faithful participant answer, to which the receiver added the venue.
Neither copy reviewer inspected the generated image. Exact production/review
inputs and returns are retained with each contribution.

An optional HTML preview could not run because the local Chromium executable
was absent. An available ImageMagick downscale and actual image viewing
provided the inspected small preview. The HTML source is retained as an
unrendered optional companion, with its failed attempt identified. The selected
cards are flattened rasters; no layered text master or deterministic image
regeneration is claimed. Each movement used one creative raster generation;
the small previews are inspection derivatives of those selected files.

## Public export and return to the method

The completed field was copied into this public example. Volatile generated
output paths, the unavailable browser's cache path and the installed generic
imagegen-skill resource were replaced with named runtime placeholders. The
selected media, copy, alternative text, production prompts and retained review
inputs/returns kept their exact receiving bytes. The second contribution's
asset manifest identifies the exported files and records the original
receiving manifest's digest.

The source validator then exposed a real export defect: the second receiver
had preserved a copy of the earlier studio method whose relative links still
assumed its original `methods/` location. The export retained that snapshot's
exact bytes as historical text, made its reference base explicit and corrected
the active navigation. The receiver's earlier route check covered its entry,
method and contribution index; it had not established every archived copy's
reachability.

That finding also changed the public
[media production and continuity method](../../skills/social-media-composition/references/production-and-continuity.md).
It now teaches preserving snapshot identity and reference base, distinguishing
historical archives from active navigation, and checking material routes from
their actual consumer location after transfer. This is a source correction
after the frozen exercise; its later use by another receiver is not claimed.
The final exported source passed the declared local-route validation.

## What these observations support

contribution from model ability and host assistance, establish native plugin

A later real receiving trial has its own source and evidence.
