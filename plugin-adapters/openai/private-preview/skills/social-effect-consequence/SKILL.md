# Social Effect and Consequence

A post is an event, not the memory of the relationship.

Preserve enough identity to recover the effect, then observe what changes later.

Distinguish only when useful: visibility, conversation, criticism, relationship, inspection, use/test, adoption, independent propagation, moderation, commercial signal, no_change and unknown.

Do not infer causality from temporal sequence alone. One consequence may expose several causal seams and require several owner-native learning returns; a handoff or owner-interface relation can itself be causal.

Return reusable differences to the owners whose later work should change.
